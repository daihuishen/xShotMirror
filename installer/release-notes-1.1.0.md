xShot Mirror 1.1.0 adds audio playback while mirroring your iPhone to Windows.

- Mirroring audio uses the current default Windows output device through WASAPI.
- Includes the required audio conversion, resampling, volume, level, and Windows audio output plugins.
- Keeps windowed/full-screen viewing, PIN pairing, English/Chinese installation, and the default desktop shortcut.

Download `xShotMirror-1.1.0-win-x64-Setup.exe` for Windows 10 22H2 or Windows 11 on Intel/AMD x64. Close xShot Mirror before installing the update. .NET and the audio/video runtime are included. Apple Bonjour must be installed separately with Bonjour Service running. Connect the iPhone and PC to the same local network.

Recording and DRM-protected playback are not supported. The installer is unsigned. `SHA256SUMS.txt` provides download hashes; `xShotMirror-1.1.0-sources.zip` includes the matching application and dependency sources.
